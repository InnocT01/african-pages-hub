# KitabuShop — Marketplace de Littérature Africaine

KitabuShop est une marketplace premium dédiée à la littérature et aux contenus éducatifs africains. La plateforme connecte les auteurs, éditeurs et lecteurs à travers l'Afrique subsaharienne, l'Afrique de l'Est et la diaspora.

## Fonctionnalités

- **Catalogue complet** : Romans, BD, livres audio, manuels scolaires, langues nationales
- **Espace Créateur** : Tableau de bord pour publier, gérer et suivre les ventes
- **Espace Lecteur** : Bibliothèque personnelle, suivi de lecture, liste de souhaits
- **Bilingue** : Interface disponible en français et anglais
- **Panier & Checkout** : Support Mobile Money et carte bancaire
- **Filtres avancés** : Par origine, genre, type de contenu

## Technologies

- React + TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui
- Supabase (base de données, authentification, stockage)

## Développement

```sh
npm install
npm run dev
```

## Déploiement

L'application peut être déployée via Lovable ou tout hébergeur compatible avec Vite/React.
